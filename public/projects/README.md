# Project images

Drop real project screenshots here. The site references them from
`src/content.ts` via the `image` field and falls back to generative
art if a file is missing.

Expected files (referenced in content.ts):

- `weaver.jpg`  — screenshot of https://weaver-vert.vercel.app/
- `reflect.jpg` — screenshot of https://reflect-gamma-one.vercel.app/

Any wide image works; it's shown grayscale, object-fit: cover.
Recommended ~1600×1067 (3:2) for the overlay, JPG or PNG.
